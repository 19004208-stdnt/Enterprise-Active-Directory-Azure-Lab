Challenges & Solutions

During this project, I faced real infrastructure issues and resolved them through troubleshooting.

VM Size Not Available

Challenge: Some VM sizes were unavailable in selected Azure regions.

Solution: Changed region and selected an available B-series VM size.

VNet Region Mismatch

Challenge: The VM could not use the existing VNet because it was in a different region.

Solution: Recreated the VNet and NSGs in the same region as the VM.

RDP Connection Failed

Challenge: Remote Desktop could not connect to the server.

Solution: Checked public IP, enabled RDP port 3389, and verified NSG inbound rules.

AD DS Prerequisite Error

Challenge: Domain Controller promotion failed because a restart was required.

Solution: Restarted the server and reran the promotion wizard successfully.

Domain User Login Testing

Challenge: Domain users did not appear immediately on the login screen.

Solution: Used domain logon format such as UNIVEN\username and reviewed logon policies.

Subscription Limitation

Challenge: Azure blocked creation of an additional Windows 11 VM due to subscription limitations.

Solution: Continued testing on the Domain Controller and planned client testing for a later stage.
